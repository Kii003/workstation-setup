# PowerToys

PowerToys covers what Raycast and Rectangle do on macOS:

| Tool | What for | Default shortcut |
|---|---|---|
| PowerToys Run | launcher (apps, files, calculator) | `Alt + Space` |
| FancyZones | snap windows into layouts | `Win + Shift + ´` (editor) |
| Keyboard Manager | remap keys and shortcuts | – |
| Text Extractor | copy text from anything on screen | `Win + Shift + T` |

**Backup / restore:** PowerToys → Settings → General → Backup & restore. Point the backup location at this folder (or copy the backup file here) and commit it; on a new PC choose Restore.
