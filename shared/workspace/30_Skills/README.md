# 30_Skills - skill sources

Your own skills while you build them: one folder per skill with a `SKILL.md` (template: `../_templates/skill/SKILL.md`).

Where a finished skill goes:
- **Claude Code on every machine:** copy it to `shared/claude/skills/` in your workstation-setup repo - the setup links it into `~/.claude/skills/`
- **Claude apps (desktop/web):** upload it to your Claude account (Settings → Skills)
- **Third-party packs** (e.g. Matt Pocock's): install as a plugin instead (`shared/claude/plugins.txt`)

Build a skill only after you've repeated a procedure ~3 times.
