# Raycast

Raycast settings can't be scripted, but they can be exported and imported:

- **Export** (old Mac): Raycast → Settings → Advanced → Export → save the `.rayconfig` here. Set a password when asked so the file is encrypted.
- **Import** (new Mac): Raycast → Settings → Advanced → Import.

The export contains hotkeys, snippets, quicklinks and extension settings.

## First-time setup (no export yet)

1. System Settings → Keyboard → Keyboard Shortcuts → Spotlight → turn off "Show Spotlight search"
2. Raycast → set hotkey to `Cmd + Space`
3. Enable: Clipboard History (`Cmd+Shift+V`), Window Management, Snippets
4. Window Management hotkeys, e.g. `Ctrl+Alt+←/→` for halves, `Ctrl+Alt+Enter` to maximize
5. Quicklinks for the sites/tools you open every day
